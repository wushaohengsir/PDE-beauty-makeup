## 产品概述

The Ordinary 明星单品之一，一款 **10% 烟酰胺（维生素 B3）+ 1% 锌 PCA** 的高浓度水基精华，针对易出现瑕疵、出油、毛孔粗大的肌肤。主打控油、淡化瑕疵/色素沉着、缩小毛孔可见度、提亮肤色并强化皮肤屏障。配方水基轻薄，不含香精、不含硅油、不含硫酸盐，纯素且零残忍。

## 核心功效

- **控油**：10% 烟酰胺 + 1% 锌 PCA，宣称 3 天内改善出油
- **淡化瑕疵/色素沉着**：烟酰胺抑制黑色素向角质细胞转移，改善痘印、肤色不均
- **缩小毛孔可见度**：临床测试显示 4 周内毛孔最小化
- **提亮光滑**：宣称一周内改善肌肤光泽、平滑质地
- **强化屏障**：烟酰胺促进神经酰胺合成，增强皮肤屏障
- **改善泛红**：具一定舒缓作用

## 使用方法

1. **清洁后**使用（可在水基精华步骤）
2. 取**几滴**涂抹于面部，**早晚均可使用**
3. 轻柔按摩至吸收
4. 后续搭配保湿霜及常规护肤步骤
5. **日间配合防晒**
6. **使用前进行贴片测试**，避免用于皮肤破损处

### 贴片测试
取少量涂抹于上臂内侧清洁皮肤，24 小时后观察；如出现红肿、灼烧、瘙痒或水泡，不得使用。

### 成分搭配与冲突

| 搭配成分 | 建议 |
|---------|------|
| **透明质酸 / 防晒霜 / 大多数成分** | 可搭配，烟酰胺兼容性良好 |
| **视黄醇（A 醇）** | 可搭配，烟酰胺有助于缓解 A 醇刺激，经典协同组合 |
| **α-熊果苷** | 可搭配（见知识库 The Ordinary α-熊果苷条目） |
| **纯维生素 C（L-抗坏血酸）** | 历史争议：低 pH 环境下烟酰胺可能转化为烟酸致泛红。The Ordinary 建议避免与纯维 C 同步骤使用；如需同用可错开时间（如早晚分开），或选用维 C 衍生物 |
| **酸类（AHA/BHA）** | 一般可同流程，但高浓度酸类与高浓度烟酰胺叠加可能增加刺激，建议观察耐受或错开 |

### 特殊人群

| 场景/人群 | 建议 |
|---------|------|
| 孕期/哺乳期 | 烟酰胺为维生素 B3，外用一般被认为安全，属低风险；如有顾虑遵医嘱 |
| 敏感肌 | 需测试，10% 浓度偏高，建议从低频建立耐受 |
| 婴幼儿 | 不建议 |

## 临床/作用依据

- **烟酰胺（维生素 B3）**：多项临床研究证实其可减少皮脂分泌、改善毛孔外观、淡化色素沉着（抑制黑色素向角质细胞转移）、增强屏障（促进神经酰胺合成）、抗炎舒缓
- **锌 PCA**：皮脂腺调节作用的矿物质，控油收敛，常用于痘痘/油性肌肤配方
- **10% 浓度**：为烟酰胺常见有效浓度上限，功效显著但需注意耐受；市售烟酰胺产品浓度多在 2%–10% 之间
