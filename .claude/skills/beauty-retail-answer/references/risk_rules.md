# 风险分级规则

## 三级分类逻辑

风险分级的核心问题是：**答错了会有什么后果？**

| 后果 | 等级 | 策略 |
|------|:---:|------|
| 危及健康安全 | 高 | 回答 + 强烈建议转人工/咨询医生 |
| 可能导致不适或体验差 | 中 | 正常回答 + 额外提醒 |
| 仅涉及产品信息 | 低 | 正常回答，无需额外警示 |

---

## 高风险（直接建议转人工）

### 触发词
孕期、怀孕、哺乳期、过敏、起疹子、红肿、刺痛、灼烧、湿疹、玫瑰痤疮、医美后、激光后、刷酸后、药物、婴幼儿、儿童、宝宝

### 具体场景
| 场景 | 示例问题 |
|------|---------|
| 孕期/哺乳期 | "怀孕能用吗""哺乳期用这个安全吗" |
| 过敏/刺激反应 | "用了之后脸红了""起疹子了还能用吗" |
| 严重皮肤病 | "玫瑰痤疮能用这个吗""湿疹用" |
| 医美术后 | "打完激光能用吗""做了光子嫩肤后用" |
| 药物相互作用 | "在吃异维A酸，能涂这个吗" |
| 婴幼儿 | "给宝宝用""3岁孩子能用吗" |

### 处理策略
即使知识库有相关信息，也必须在回答末尾追加：
> ⚡ **建议转人工客服进一步确认。** 您的情况涉及{具体风险类别}，每个人的体质不同，需要专业人员为您评估。

---

## 中风险（正常回答 + 提醒）

### 触发词
搭配、冲突、同时用、叠加、第一次用、新手、敏感肌、过敏体质（无明确过敏史）、开封、保质期、顺序

### 具体场景
| 场景 | 示例问题 |
|------|---------|
| 成分冲突/搭配禁忌 | "和维C能一起用吗""能叠涂几个精华吗" |
| 敏感肌（无明确过敏史） | "敏感肌能用吗" |
| 首次使用 | "第一次用要注意什么" |
| 开封/保质期 | "开封后能用多久""过期了还能用吗" |
| 使用顺序 | "先用这个还是先用面霜" |

### 处理策略
正常回答 + 附加提醒：
> 📌 **小提醒**：{具体提醒内容，如贴片测试、错开时间使用等}

---

## 低风险（正常回答）

### 覆盖范围
- 产品功效说明
- 价格、规格、品牌信息
- 成分列表查询
- 常规使用方法
- 适用肤质（非敏感肌/无明确高风险因素）
- 非禁忌的搭配建议

### 处理策略
直接按模板回答，无需额外风险标记。

---

## 灰色地带处理

当问题同时触发多个风险条件时：
- 取**最高**等级
- 例如："敏感肌+孕期" → 按高风险处理
- 例如："第一次用+和维C搭配" → 仍为中风险，但提醒加倍

## 边界判断

不确定是否属于高风险时，**按高风险处理**。过度谨慎的代价远低于风险遗漏。
