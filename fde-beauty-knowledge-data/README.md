# 美妆零售知识库模拟数据使用说明

> 本包为 FDE 共学营使用的脱敏模拟材料，不代表真实企业制度或专业意见。

## 文件内容

- `01-product-label.md`：商品信息与标签核对。
- `02-inventory-expiry.md`：收货、库存与效期管理。
- `03-claims-consulting.md`：功效宣称与顾客咨询边界。
- `04-return-complaint.md`：退换货、质量投诉与证据留存。
- `05-adverse-reaction.md`：疑似不良反应记录与升级。

## 使用方法

1. 将 5 个 Markdown 文件导入飞书文档，作为模拟企业知识库。
2. 基于这些文档构建知识检索与问答工具。输出至少包含用户问题、实际答案、引用的知识文档及原文位置、是否需要人工确认。
3. 自行创建包含“知识库问题、预期答案、实际答案”的测试题集，并结合业务风险确定验收阈值。

参考标准：整体答案准确率达到 80% 以上，且没有编造信息或遗漏必须转人工的高风险问题，可确认系统有效。

本包不包含测试问题、预期答案、准确率结果或验收结论。
