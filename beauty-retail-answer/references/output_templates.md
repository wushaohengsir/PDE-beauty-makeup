# 回答输出模板

根据不同场景，使用对应的模板。选择模板的逻辑在 SKILL.md 工作流程第四步中定义。

---

## 模板 A：知识库有匹配

```markdown
## 回答

### 用户问题
{回显用户原问题}

### 答案
{核心回答——先给结论，再给细节。口语化，分段呈现。}

### 依据来源
- 📄 **文件**: `{文件名.md}`
- 📝 **原文**: "{引用的知识库原文段落，一字不改}"
```

### 答案部分写作要点
1. **先给结论**："可以"还是"不可以"、"有用"还是"没用"——第一句就说明白
2. **再给细节**：为什么、具体数据、使用方法
3. **成分名保留原文**（α-熊果苷、Niacinamide），附中文说明
4. **不说废话**：不要"您好！很高兴为您服务～"之类的开场白

---

## 模板 B：知识库无匹配 + 中/高风险

```markdown
## 回答

### 用户问题
{回显用户原问题}

### 答案
抱歉，目前我们的产品知识库中暂时没有覆盖到您询问的这个问题。

### 建议
⚡ **建议转人工客服处理**。这个问题涉及{风险类型说明，如孕期安全/过敏反应/成分冲突}，需要专业人员为您提供更准确的解答，避免因信息不完整而对您造成影响。
```

> 风险类型说明要具体，不要只说"涉及安全风险"——要说清楚"涉及孕期护肤品使用安全性"。

## 模板 C：知识库无匹配 + 低风险

```markdown
## 回答

### 用户问题
{回显用户原问题}

### 答案
抱歉，目前我们的产品知识库中暂时没有覆盖到"{具体询问的产品或成分名}"的相关信息。建议您直接查阅产品官方说明书或联系品牌方获取最准确的信息。

### 建议
如果您有更多信息或想了解其他产品，我可以继续为您查询。您也可以联系在线人工客服。
```
