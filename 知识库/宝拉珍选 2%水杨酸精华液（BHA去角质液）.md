## 使用方法

1. 作为**清洁后第一步**（前导去角质，非化妆水）
2. 用化妆棉沾取适量，由内而外擦拭面部与颈部；或直接用手轻拍吸收
3. **避免接触眼睛及嘴唇**
4. 后续搭配精华液、保湿产品
5. **白天必须搭配防晒**——去角质后皮肤对紫外线更敏感
6. **逐步建立频率**：
   - 初期：**三天使用一次**
   - 适应后：逐渐增加至**每天早晚使用**
   - 依个人肤况调整

清洁 → 前导去角质（2% 水杨酸精华液）→ 精华液 → 乳霜 → 日间防晒

### 特殊人群与场景

| 场景/人群 | 建议 |

| **水杨酸过敏者** | 使用任何含水杨酸产品前请先咨询皮肤科医生 |
| **孕期/哺乳期** | 外用 2% 水杨酸一般被认为风险较低，但高浓度/大面积使用存在争议，建议遵医嘱 |
| **医美/特殊美容后** | 恢复期内肌肤敏感，建议咨询皮肤科医生，待恢复后再依医嘱使用，并注意调整频率 |

### 成分搭配（来自品牌 Q&A）

| 搭配成分 | 建议 |
|---------|------|
| **果酸（AHA）** | 可搭配，建议分早晚或分天使用，非必须同时 |
| **烟酰胺（B3）** | 协同效果好，水杨酸疏通毛孔帮助 B3 渗入；B3 非替代而是增强 |
| **杜鹃花酸（壬二酸）** | 可叠加，杜鹃花酸作用表层、水杨酸作用毛孔内，适合敏感/痘痘肌 |
